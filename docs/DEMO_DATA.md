# Demo data

Everything here is **synthetic**. The protocols are generated PDFs, and the patients are fictional
profiles with labels starting "Synthetic patient". No real patient data is used anywhere.

Load the data into any running backend, local or deployed:

```bash
cd backend
python -m scripts.seed --api-url http://localhost:8000 --analyze
# or against Render:
python -m scripts.seed --api-url https://cte-system-api.onrender.com --analyze
```

The seed script is idempotent: it skips protocols and patients that already exist.
`--analyze` runs the nine reference assessments below.

Demo login: `demo@example.org` / `demo-password-123`. The login page also has a
**Use the demo account** button.

## Protocols

The PDFs are generated by `backend/scripts/make_synthetic_protocol.py` into `backend/tests/fixtures/`.
Each has three pages: page 1 is the synopsis, page 2 the inclusion criteria and page 3 the
exclusion criteria.

| Title | File | Criteria |
|---|---|---|
| SYN-RENAL-001 (severe renal impairment undefined) | `protocol_renal.pdf` | Inclusion: age 18–70; eGFR ≥ 30. Exclusion: severe renal impairment (no numeric definition); pregnancy or breastfeeding |
| SYN-RENAL-001b (severe renal impairment defined as eGFR < 30) | `protocol_renal_defined.pdf` | Same as above, but severe renal impairment is defined numerically |
| SYN-HEP-002 (liver safety study, HP-42) | `protocol_hepatic.pdf` | Inclusion: age 18–75; platelets ≥ 100 ×10⁹/L; hemoglobin ≥ 10 g/dL. Exclusion: ALT > 120 U/L; bilirubin > 34 µmol/L; decompensated cirrhosis; pregnancy or breastfeeding |
| SYN-CARDIO-003 (heart failure study, CV-9) | `protocol_cardio.pdf` | Inclusion: age ≥ 40; LVEF ≤ 40 %; HbA1c < 10 %. Exclusion: myocardial infarction within 90 days; QTc > 470 ms; potassium > 5.5 mmol/L; pregnancy or breastfeeding |

## Reference assessments

These outcomes come from the real pipeline. Nothing is hard-coded: the tests in
`backend/tests/test_acceptance.py` and `backend/tests/test_demo_scenarios.py` re-run them
and assert the results.

| Protocol | Patient | Overall | Why |
|---|---|---|---|
| SYN-RENAL-001 | A | NOT_ELIGIBLE | eGFR 28 fails INC-02; "severe renal impairment" is undefined, so EXC-01 is UNKNOWN and flagged; renal silent exclusion trigger cites pages 2 and 3 |
| SYN-RENAL-001 | B | ELIGIBLE | All criteria met |
| SYN-RENAL-001b | A | NOT_ELIGIBLE | With the numeric definition, EXC-01 is TRIGGERED |
| SYN-HEP-002 | E | ELIGIBLE | All criteria met |
| SYN-HEP-002 | F | NOT_ELIGIBLE | ALT 185 > 120 and bilirubin 52 > 34 µmol/L trigger EXC-01 and EXC-02; hepatic trigger |
| SYN-HEP-002 | G | MORE_INFORMATION_REQUIRED | Platelet count is stale (over 90 days old); cirrhosis status is unknown |
| SYN-CARDIO-003 | H | ELIGIBLE | The prior MI (2024) is outside the 90-day window |
| SYN-CARDIO-003 | I | NOT_ELIGIBLE | MI 42 days ago and QTc 482 ms trigger EXC-01 and EXC-02; cardiac trigger |
| SYN-CARDIO-003 | J | MORE_INFORMATION_REQUIRED | LVEF missing; potassium 4.2 and 5.8 recorded on the same date conflict |

Pairing a patient with another study's protocol, such as a heart patient against the liver
protocol, mostly gives MORE_INFORMATION_REQUIRED. That is expected: the labs the protocol needs
are missing, and the system reports them as missing rather than guessing.
